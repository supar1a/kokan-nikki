# 短冊

仲間うちだけで、縦書きで、本音や雑記を書き散らせる場所。

- **返事はいらない。** 誰かに宛てて書くのでも、応えるのでもない。
- **順番も手番もない。** 誰でも、いつでも書ける。
- **整っていなくていい。** エッセイである必要も、日記である必要もない。
- **いいね・既読・閲覧数・フォロワー数は、一つも作らない。** 数えないことが、この場の性格そのもの。
- **日記ほど私的すぎず、SNSほど公的すぎない。** 濃い文脈が共有されている前提で書ける。
- **縦書きで「読む」。** タイムラインを眺めるのではなく、文章を読む。

## 巻物

グループを開くと、全員の短冊が**全文のまま、右から左へ連なっている**。
右端がいちばん新しい。開いた瞬間に、もう誰かの文章を読んでいる状態になる。

- カードも、抜粋も、「続きを読む」もない。**走り読みという行為が成立しないようにしてある。**
- 本文はリンクではない。読むもの、引用するものなので。
- リンクなのは**書いた人の名前**（その人の分だけを続けて読む）と**日付**（その一枚だけを開く）。
- 前に見たあとに書かれた分の手前に、細い朱の目印が入る。**未読の「数」はどこにも出さない。**
  数が出た時点で、消化すべきものになってしまうので。

## 言葉づかい

機能の名前は、ウェブで通じている言葉をそのまま使う（投稿・下書き・公開・編集・削除・メンバー・ログアウト）。
雰囲気は、本文と佇まいの側で出す。

例外は**合言葉**。グループに入るための符牒で、作った人が決める。
`kmp4-t7xz` のような羅列ではなく、口で言って渡せる言葉にしておける。

## 動かす

```sh
brew install postgresql@17                                   # まだ無ければ
pg_ctl -D /opt/homebrew/var/postgresql@17 start              # 起こす
createdb kokan_nikki

npm install
cp .env.example .env        # DATABASE_URL と AUTH_SECRET を埋める
npx prisma migrate dev
npm run seed                # 手ざわりを見るための種データ（任意）
npm run dev
```

`AUTH_SECRET` は `node -e 'console.log(require("crypto").randomBytes(32).toString("base64url"))'` で作れる。

### 開発中のログイン

`/login` の下に「開発用」の貼り紙が出る。人の釦を押せばそのまま入れる。
本番ビルドでは出ないし、その処理も中身ごと消えて `throw` だけが残る。

種データを入れると、はなこで入ったときに未読の目印が出る状態から始まる。
グループ「三人のところ」の合言葉は `ゆうやけ`。

## 名乗り

**名前を入れるだけで始められる。** 次に来るための「ログイン用URL」を一度だけ渡す。

ほかの入口も、鍵が入っていれば出る。

- **Google** — `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET` があるときだけ。
- **メールに届くリンク** — 本番では `RESEND_API_KEY` があるときだけ出す。
  無いのに出すと、送ったつもりで誰も入れない行き止まりになるため。

公開 URL を知っていれば誰でも名乗りを作れるが、**グループの中身は合言葉を知る人しか見られない**。
ログイン試行の回数制限はまだ入れていない。

## 画面

| 道筋 | なに |
|---|---|
| `/login` | 名前だけで始める。鍵があれば Google とメールも |
| `/modoriguchi` | ログイン用URLを見せる・作り直す |
| `/` | 入っているグループの一覧 |
| `/new` | グループを作る・合言葉で参加する |
| `/b/[slug]` | 巻物。右端が最新 |
| `/b/[slug]/write` | 書く |
| `/b/[slug]/by/[userId]` | その人の分だけを続けて読む |
| `/b/[slug]/members` | メンバーと合言葉 |
| `/s/[id]` | 一枚だけを開く |
| `/s/[id]/edit` | 編集 |

## 見えかた

| | グループの外 | メンバー | 書いた本人 | 作成者 |
|---|---|---|---|---|
| グループを見る | ✕（404） | ○ | ○ | ○ |
| 公開された短冊を読む | ✕ | ○ | ○ | ○ |
| 下書きを読む | ✕ | ✕ | ○ | ✕ |
| 編集・削除・公開の切替 | ✕ | ✕ | ○ | ✕ |
| 合言葉の変更・メンバーを外す | ✕ | ✕ | — | ○ |

見せてはいけないものは 403 ではなく **404** を返す。存在そのものを伏せるため。

## 中身

- Next.js（App Router）+ Server Actions
- Prisma + PostgreSQL
- 名乗りは Auth.js（NextAuth v5）。セッションは DB の表で持つ
- 紙の質感は画像を使わず、SVG のノイズと繊維の重ね合わせ
- 音は音源ファイルを持たず Web Audio でその場で合成（右上の「音」で止まる）
- スタイルは `app/globals.css` 一枚。縦組みは `writing-mode: vertical-rl` と論理プロパティ
  （縦組みでは `inline` が上下、`block` が左右。仕切りの罫は `block` 側に引く）

```
auth.ts            Auth.js の設定
lib/mail.ts        ログイン用リンクの届け方（RESEND_API_KEY があれば実送信）
lib/auth.ts        いま名乗っている人・セッションの発行
lib/place.ts       未読の目印の位置
lib/guards.ts      グループと短冊の見せてよさ
lib/kanji.ts       日付を漢数字に
lib/sound.ts       紙の音の合成と、消音の状態
app/actions/       server actions（auth / places / slips）
components/        巻物の一枚・書く場・戸口・音まわり
```

## 公開する（Vercel）

GitHub に push すると Vercel が拾って公開しなおす。環境変数は二種類だけ。

| 名前 | どこから |
|---|---|
| `DATABASE_URL` / `DATABASE_URL_UNPOOLED` | Vercel の Storage で Neon を繋ぐと自動で入る |
| `AUTH_SECRET` | 自分で作って入れる |

`npm run build` が `prisma migrate deploy` を先に走らせるので、表の移行は公開のたびに当たる。

### 自動で公開されないとき

Vercel の無料プランは、**Git のコミット作者がアカウント所有者と結びつかない場合、
そのデプロイをブロックする**（GitHub 側に「Deployment was blocked」と出る。ビルドの失敗ではない）。
コミットの作者メールを、GitHub が自分だと認識するものにすれば直る:

```sh
git config user.email "<あなたのID>+<ユーザー名>@users.noreply.github.com"
```
